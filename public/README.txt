ASSETS REQUIRED

1. Put the 280 hero frames in this folder:
   public/StaringVideo/

2. Default naming:
   frame_0001.jpg
   frame_0002.jpg
   ...
   frame_0280.jpg

If your names differ, change FRAME_PATH() in src/main.jsx.

3. Put the feature video here:
   public/feature-video.mp4

4. Optional:
   public/feature-poster.jpg

5. Replace the placeholder beta URL:
   https://example.com
   in src/main.jsx

The page intentionally waits until all 280 hero images have attempted to load before enabling the main experience.
